Artifact Two: Data Structures and Algorithms

AVL Tree Creation in C++

The artifact for this milestone was the final project from CS 300: Data Structures and Algorithms. The project is a binary search tree, where the focus of the project was creating a data structure with appropriately implemented algorithms to have a self-sorting data structure that sorts relevant data on insertion. I created this artifact over a year ago now in C++ and for my enhancement I decided to create an alternative, yet more efficient version of a binary search tree called an AVL tree. AVL trees are binary search trees that are auto-balancing. This means that as the sub-trees of a given node become unbalanced or as the difference between their heights is greater than 1, the AVL tree will automatically perform rotations too ensure the balance remains less than or equal to 1.

I think that the AVL tree is a good addition to my ePortfolio as it is a good example of utilizing modern computer science techniques to make an algorithm and data structure more efficient. The AVL tree is massively more efficient than the basic binary search tree, as it avoids a common problem with binary search trees. Since data is not guaranteed to be sorted on insertion, there is a good chance that data will be inserted in ascending or descending order. This will lead to very tall trees, and when the tree isn’t self-balancing, then the tree will perform no better than a vector or a linked list on insertion. As an example of this performance enhancement I ran some tests to measure the time difference between the two data structures, performing 10,000,000 insertions and searches of random numbers. As seen from this screenshot, the AVL tree works much more efficiently than the basic binary search tree, due to the self-balancing causing minor performance loss for a drastic performance gain. The overall expected time complexity for insertion and search for an AVL tree is logarithmic whereas for a binary search tree, in the worst case the time complexity would be linear.
